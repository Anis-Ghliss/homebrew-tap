# Anis-Ghliss/homebrew-tap

Homebrew casks for my Mac apps.

## DevNotch

A notch for developers: your Claude Code and Codex agents, pull requests and CI, in a panel that drops out of the MacBook notch.

```sh
brew install --cask anis-ghliss/tap/devnotch
```

DevNotch isn't notarized yet, so macOS blocks it on first launch. Open it once, then allow it under **System Settings → Privacy & Security → Open Anyway**. After that it updates itself.

Releases: [devnotch-releases](https://github.com/Anis-Ghliss/devnotch-releases)
